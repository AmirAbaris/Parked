# Parked

Parked is an iPhone app that helps you remember where you left your car, especially when a location estimate alone isn't enough.

Save one active parking memory with an optional photo and details such as floor, section, spot, landmark, or note. When a location estimate is available, view your distance from the car and open directions in Apple Maps. You can save and read parking memories offline; maps and directions need connectivity.

Built with SwiftUI, SwiftData, Core Location, and MapKit. The interface uses Finglish, Persian written in Latin characters.

## Run locally

1. Open `Parked.xcodeproj` in Xcode with the iOS 26 SDK.
2. Select the `Parked` scheme and an iPhone simulator or device running iOS 26 or later.
3. Build and run. For a physical device, select your development team under Signing & Capabilities.

Run the `ParkedTests` suite with **Product > Test** in Xcode.
